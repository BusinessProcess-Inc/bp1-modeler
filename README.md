# BP1 Modeler

BPMN 2.0 diagram editor for macOS and Windows by [BP1](https://bp1.ai). The same editor runs in the browser at [modeler.bp1.ai](https://modeler.bp1.ai).

**Download:** [modeler.bp1.ai/downloads](https://modeler.bp1.ai/downloads)

This repository hosts release builds only. The source code is not published here.

| System | File | Requirements |
| --- | --- | --- |
| macOS | `BP1-Modeler-mac.dmg` | macOS 13 Ventura or later, Apple Silicon or Intel |
| Windows x64 | `BP1-Modeler-Setup-x64.exe` | Windows 10 or 11 |
| Windows ARM64 | `BP1-Modeler-Setup-arm64.exe` | Windows 10 or 11 on ARM |

Preview builds are not yet signed with Apple and Microsoft certificates. The download page explains how to open them. Checksums are in `SHA256SUMS.txt` of each release.
